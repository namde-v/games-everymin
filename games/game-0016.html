GLYPH GRID

☀ ☽ ✦ ❖ ✧ ♠ ♣ ♦

How to Play: Ancient glyphs are hidden in the grid. The numbers beside each row and column tell you exactly how many glyphs hide in that row or column. Use logic — never pure guessing — to find all 12 glyphs.

DIG mode reveals a cell: a glyph scores points, an empty cell costs a mistake. FLAG mode marks a cell you believe holds a glyph. You have 5 mistakes before the run ends. A new glyph layout is carved every game, so no two games are alike.

Mouse / touch: tap a cell. Keyboard: arrow keys move, Enter digs, F flags, M switches mode. Sound starts only after you press Start.

You Win!

How to Play — Deduction Tips

  • A row or column clue of 0 means every cell there is empty — safe to clear mentally.
  • If a row clue equals the number of unrevealed cells left in that row, every one of them is a glyph.
  • Combine a row clue with a column clue: a cell at the crossing of a "full" row and a "full" column is a near certainty.
  • Flag suspects first, then dig only when the clues agree. Five wrong digs end the game.
  • Win by finding all 12 hidden glyphs. Empty cells you dig by mistake are marked with a dot.
