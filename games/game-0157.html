🧩 Mosaic Maker

How to Play:

  • A target mosaic pattern flashes on screen for a few seconds. Memorize it!
  • Then the grid clears. Pick a color from the palette and tap cells to recreate the pattern exactly.
  • Each puzzle has a move limit and a time limit. Finish before either runs out.
  • Tap Check when you think it matches, or finish all 5 puzzles to win.
  • Wrong or timed-out puzzles cost a life. Lose all 3 lives and it is Game Over.

Controls: Mouse click, touch tap, or keys 1-6 for colors, 0 for eraser, R to restart.

Scoring: +10 per correct cell, +50 puzzle bonus, +time bonus. Accuracy matters!
