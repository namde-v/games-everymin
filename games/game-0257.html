LOCKPICK LOGIC

You are a master locksmith facing a vault door with six locks. Each lock hides a five-digit tumbler code. Use the clues, set every tumbler, then turn the key.

  • How to play: Click or tap a tumbler to rotate it, or select one with the mouse and press Up / Down. Use Left / Right to move between tumblers.
  • Read the clues under the lock. They describe the hidden code: parities, sums, comparisons and one revealed digit.
  • Press Try Key when you think the code is right. A wrong key tells you how many tumblers are correct, but costs one of only 3 failed attempts.
  • Every tumbler turn counts as a move. Open all six locks to win. Three failed attempts and the vault seals shut.
  • Keys: 1-5 select a tumbler, Space rotates it, Enter tries the key, R restarts.

Sound starts only after you press Start. No downloads, no network — everything runs in this file.
