Pollen Path

How to Play

  • Start at the brown hive in the bottom-left corner.
  • Draw one continuous path that visits flowers in order: 1, 2, 3, 4, 5.
  • Your path must not cross itself, revisit a cell, or go through a thorn.
  • Stepping on a flower out of order is not allowed — collect them in sequence.
  • Win by reaching Flower 5 after collecting all five. You have 5 path attempts.
  • Pressing R (or Reset Path) clears your current path and uses one attempt. Run out of attempts and the garden closes — Game Over.

Controls: Mouse / touch drag to draw path • Arrow Keys move bee • Enter confirm • Backspace undo • R reset
