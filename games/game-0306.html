🌿 Vine Vault 🌿

Puzzle • Vine Untangling • Free the gems!

Thick vines have tangled the vault's gems into a knot. Drag the glowing nodes until no vines cross — then the vault opens.

How to Play
  • Drag any gem node with mouse or touch to move it.
  • Arrow Keys select / move the highlighted node. Space or Enter grabs or releases it.
  • Solve a level by reaching 0 crossings. Solve all 3 levels to win.
  • Watch the timer! If it runs out, the vines lock and the game ends.
  • Press R at any time to restart.

Tip: pull the outermost gems first — the middle knot usually loosens last.
