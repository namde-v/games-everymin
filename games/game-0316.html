The Sealed Stones

An ancient vault is locked by five secret rune codes, each four runes long. Read the clues, test your guesses, and let the golden and green stones guide you.

How to Play
  • Goal: Crack all 5 codes to win. Each code is 4 runes chosen from 6 runes — repeats are allowed.
  • Pick runes: Tap / click a rune in the palette to place it in the glowing slot, or tap a slot to select it first.
  • Keyboard: ← → move slot, ↑ ↓ change rune, keys 1–6 place a rune, Space / Enter confirm a guess, Backspace clear a slot.
  • Feedback: ● gold = right rune, right place. ● green = right rune, wrong place. No peg = that rune is not in the code (counting repeats carefully).
  • Clue stone: Each code starts with one true clue — use it to narrow the possibilities.
  • Limits: 10 guesses per code. Failing a code costs a life. Lose all 3 lives and the vault seals — game over. Cracking a code early scores bonus points.

Mouse, touch and keyboard all work. Sound starts only after you press Start.
