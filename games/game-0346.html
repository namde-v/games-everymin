Welcome, Codebreaker

The Engine has scrambled its cipher key. Each code is a short word made of symbols. Rotate the dials until every dial matches the secret code — but the secret is hidden. Clues are revealed one at a time, and a wrong guess costs nothing except precious seconds.

How to Play: Tap or click a dial (or its arrow button) to rotate it. Use the Swap Rotors button to exchange two neighbouring dials. Press Clue or C when you are stuck — each clue locks in one true letter, but later clues cost time. Solve 8 codes to win. Lose all 3 lives by letting the timer run out and the Engine locks forever.

Controls: Mouse / touch: tap dials and buttons. Keyboard: ← → select dial, ↑ ↓ rotate, S swap, C clue, Enter check, R restart.

No network needed. All sound is generated inside this page after you press Start.
