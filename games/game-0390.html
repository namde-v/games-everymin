Marble Machinist

Route 25 marbles correctly before 8 go astray. Marbles drop from the top in waves. Each colour belongs in the matching bin at the bottom.

  • How to play: Four diverter gates stand between the drop and the bins. Each gate steers a marble Left, Straight, or Right when it passes through.
  • Set the path before the marble arrives. A gate only affects a marble at the moment it reaches that gate — later gates can still save it.
  • Click / tap a gate row to cycle it. Keys 1–4 select a gate, Arrow Left / Right steer it, Space cycles it.
  • Start lane is the centre. A Red marble needs the leftmost bin, so its gates must add up to 2 steps left, and so on.

Correct marble: +100 points. Streaks add a bonus. Wrong bin: +1 fault.

Keyboard, mouse and touch supported. Sound starts only after you press Start.

You Win!

Press R or tap Restart to run the machine again.

Tip: watch the Next colour, count the steps to its bin, and set the gates to match. Example: a Green marble (bin 2 from the left) starting in the centre needs one step left in total.
