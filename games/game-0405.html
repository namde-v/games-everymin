Quiver Quartermaster

How to Play: You are the quartermaster of a fletching workshop, and the arrow racks are a mess. Each quiver holds up to 4 arrows.

  • Tap, click, or use the arrow keys + Enter to select a quiver and lift its top arrow.
  • Place it only onto an empty quiver or onto a quiver whose top arrow is the same type.
  • Sort all five arrow types so every quiver holds a single type. Complete a quiver for bonus points.
  • You have 50 moves. Run out before everything is sorted and the workshop day ends in defeat.
  • Undo fixes a slip, but it still counts as a move already spent? No — undo restores the move too. Use it wisely.

Keyboard: Left / Right to aim, Enter / Space to pick or place, U to undo, R for new quivers.
