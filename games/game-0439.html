CIPHER COURIER

Secret messages hide every delivery address! A Caesar cipher shifts each letter. Decode the address, then race the courier to the right house before the clock runs out.

HOW TO PLAY
1. Read the encoded address in the parcel bar below the map.
2. Use the cipher key: each letter is shifted back by the shown number to reveal the real house name.
3. Move with Arrow Keys / WASD, or click / tap anywhere to set a waypoint — the courier rides there.
4. Drive into the correct house to deliver. A wrong house costs a life!
5. Deliver all 8 parcels to win. Timer expiry or 3 wrong deliveries ends the run.
Example: shift 3, code PDLO decodes to MAIL.

Sound starts only after you press Start. No network needed — everything runs on this device.
