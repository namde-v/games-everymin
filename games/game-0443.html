🌻 Glade Gardener 🐝

How to Play: Each tile shows a garden path. Tap, click, or use arrow keys + Space / R to rotate the selected tile. Connect a continuous blooming path from the hive 🏡 to every flower 🌸. Bloomed flowers stay open. Finish all 3 rounds before the sunset timer runs out!

Wrong-tile penalty: rotating a tile that breaks a bloomed path costs one life. You have 3 lives.

Mouse / Touch: tap a tile to rotate it  •  Keyboard: arrows move, R rotates, Enter starts

You Win!

Tap Start, then rotate tiles to grow the bee path.

Selected tile: row 2, column 2 — press R or tap a tile to rotate.

Controls: Click / Tap a tile • Arrow keys to move selection • R or Space to rotate • Enter to start / restart
