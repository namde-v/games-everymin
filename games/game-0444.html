Harbor Herald

How to Play: A lighthouse flashes a signal rhythm for each ship. Watch and listen, then drum the same pattern back before the ship reaches the rocks.

Signals use three drums: Low (A / left), Mid (S / middle), High (D / right). Tap the drums, press A / S / D, or use the number keys 1 / 2 / 3.

Match the whole pattern to guide the ship home. A wrong drum or a missed signal sends it off course and costs a life. Guide all 8 ships to win.
