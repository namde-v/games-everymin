Umbra Unlocker

How to Play: You are a shadow locksmith. Six vaults stand between you and the Umbra treasure. Each vault hides a secret 3-dial code. Every dial shows a shadow symbol from 0 to 7.

Read the clues under the shadow window — sums, differences, parity, and ranges narrow the code down. Rotate each dial until your guess matches the hidden pattern, then press UNLOCK. A correct code opens the vault and scores points. A wrong code costs one of your 3 master attempts.

Win by unlocking all 6 vaults. Game Over after 3 wrong master attempts. Use the Hint button if you are stuck, but it costs 25 points. The shadow pattern on the canvas glows brighter as more of your dials match the secret.

Controls: keyboard arrows + Enter, mouse clicks, or touch taps. Audio is procedural and starts only after you press Start.
