KEPLER KEEPER

Save the satellites before their orbits decay!

How to Play: Each ring carries coloured satellites. A target colour is shown for every ring. Rotate a ring until the satellite sitting in the gold dock at the top matches that ring's target colour. A matched ring locks with a green glow.

Watch out: as orbits decay, unlocked rings slowly drift on their own. Finish every ring before the timer runs out, or you lose a life. Clear all 5 levels to win.

Controls: Tap a ring (or press 1-4) to select it, then rotate with the on-screen arrows, Arrow keys / A D, or swipe-style taps. Up / Down changes the selected ring.

Keyboard: 1-4 select  |  ← → or A / D rotate  |  ↑ ↓ change ring  |  Enter start / restart
Mouse / touch: tap a ring to select it, then tap the rotate buttons.
