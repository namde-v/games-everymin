Herb Garden Potion Sort

A cosy water-sort puzzle from the herb garden.

  1. Tap a vial to pick it up, then tap a second vial to pour its top herb layer.
  2. You may pour only onto an empty vial or onto the same potion colour.
  3. Sort every vial so it holds one pure colour before your moves run out.
  4. Complete all 4 levels to win the game. Keyboard players: use ← → and Enter.

Each pure vial earns points. Each pour costs one move — plan carefully!
