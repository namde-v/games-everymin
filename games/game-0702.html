Press Start, then rotate tiles to power the board.
How to play: Tap, click or use arrow keys + R to rotate a tile 90°. Power flows only where two neighbouring tiles point at each other. Light all chips on the board to clear the level. Each rotation costs 1 move. A powered tile pointing off the edge is a SHORT CIRCUIT and blocks a win — rotate it away. You lose if moves or time run out. Clear all 3 levels to win.

Click / Tap = rotate clockwise • Q = counter-clockwise • Arrows = move cursor • Space / Enter / R = rotate • Power = yellow source • Chips = blue squares
