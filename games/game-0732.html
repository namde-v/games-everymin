⚙ Clockwork Beetle Maze

A tiny brass beetle needs a road made of gears.

Tap a gear tile to rotate it 90°. Line up the brass tracks so they form one continuous path from START to GOAL. Then press Run Beetle and watch it trundle along.

Each level gives you a limited number of rotations. A failed run costs a life. Finish all 5 levels to win!

Mouse / touch: tap a tile to rotate it. Keyboard: arrow keys move the brass selector, Space or R rotates the selected tile, Enter runs the beetle, Backspace resets the level.

Tracks must meet on both sides: a tile pointing east only connects to a neighbour pointing west. Corner tiles turn the path, straight tiles go through, T tiles branch.

You Win!

Rotate the gears, then run the beetle.

Tip: start from the START tile and follow where its track should go. A glowing track means two neighbours agree; a dull track means a break.
